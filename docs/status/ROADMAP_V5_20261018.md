# Pythia v5 roadmap (as of 2026-10-18)

## Tightening update (2026-10-18)

The frozen NLI kernel now includes a heterogeneous-support Chernoff endpoint
that preserves every row's outcome-blind score range. It beat the prior
row-range Hoeffding endpoint on 40/40 informative fresh mechanism runs and
25/25 informative separate OOD-language runs, with no observed known-law
violations. Median improvement was 1.9% and 1.3%, respectively. This is a real
but incremental tightening; see
`docs/theory/HETEROGENEOUS_SUPPORT_CHERNOFF_20261018.md`. It remains
conditional pending proof/numerical audit and patient-cluster extension.

## 3. Decisions recorded

- Certified claims use cohort (conditional-on-design) targets. Population claims add a Chernoff–KL lift.
- Text information is reported as a lower bound only. Any upper statement must carry an assumption tag.
- Models never affect validity, only tightness. Every model in a portfolio spends a share of α.
- Stratified certificates are maps, not the headline global bound.


## 2026-10-18 update: local-risk certificate v2 (literature + simulations)

Details: `docs/experiments/PYTHIA_LOCAL_RISK_V2_SIMULATIONS_20261018.md`, `docs/theory/LOCAL_RISK_V2_SPLIT_PARTITION_TRANSPORT_20261018.md`, `docs/literature/PYTHIA_LOCAL_RISK_LITERATURE_20261018.md`.

- **Finding:** the OOF-based Mayo local-W30 replay produced wrong certified directions in 19/19 simulated replicates (5.6% of certified rows), although every node interval covered its stated estimand. Causes: (i) backoff cases differ from the node they back off to; (ii) OOF fold models certified, refit deployed.
- **Implemented (opt-in, defaults unchanged):** `alpha_ledger="eligible"`, `relation_test="contrast"`, `build_support_partition`, `pythia/core/local_transport.py` (odds transport, tipping Lambda, anytime-valid harmful-shift monitor).
- **Recommended route:** split calibration + support partition + eligible ledger + contrast -> 0 wrong directions, 2.8x the certified share of a naive split.
- **Next:** re-run the Mayo local W30 replay locally with the recommended route (aggregates only); plan `min_entities` from a width tolerance before outcomes; average-coverage pooling tier; hierarchical top-down testing; non-binary transport.
